# Tide 0.9.2-test.6

- 关闭键打开 Tide 自己的主题菜单，透镜、深色透镜、点阵分别使用对应配色。选择「收起到系统托盘」后隐藏主窗口并移除任务栏窗口项；点击托盘图标恢复。普通最小化键保持普通最小化。音频和独立桌面歌词继续运行。
- 灵感模式每次切歌只在当前歌曲后准备 **一首随机歌曲**，参考整个原始列表的轮换取样和喜欢权重。候选按来源权重随机抽取，避免队列重复和最近 100 首推荐；切歌后撤掉未播放的旧推荐，防止批量积压。原歌单歌曲仍保留在队列。普通模式仍按原歌单顺序，每页 100 首、剩 10 首预读。
- 今日潮汐目标 **20 首**，列表标题旁提供「刷新今日潮汐」。刷新优先选择上一份列表以外的歌曲；数据不足时显示实际可获取数量。若当前歌曲来自已展示的潮汐列表，刷新保留当前歌曲、播放状态和进度，替换后续队列；刷新失败或没有歌曲时保留原列表。
- 切回透镜时销毁点阵 Field、画布和 GPU 纹理，移除点集按钮、TIDE 标题；点阵场景开关自动清除，恢复单一液态玻璃外壳。
- 前台优化：删除被原版外壳覆盖的旧 CSS 背景时钟；玻璃合成过滤歌词的逐帧 DOM 变化、限制物理像素预算；空闲装饰背景有独立刷新预算，交互期间提高更新频率。点阵默认从 65,536 个粒子改为 16,384 个，控件共享时钟按需运行。Paper 背景使用受控的单帧推进，避免在只需要低频纹理拷贝时持续全速渲染。
- 逐字歌词改用缓存字形的遮罩变换，减少动态渐变、模糊和大范围发光的重绘；缓存时间行和文字测量，仅更新变化的字。仍直接跟随真实音频时钟，保留平滑填色、当前行缩放、手动滚动与恢复跟随。桌面歌词的渲染与帧率保持独立。
- 包含音乐脉络独立页面、四层导航、主题配色、节点文字避让，以及封面切换、浮动曲目菜单和可读下拉选项等前序改动，详见 [TEST5.md](TEST5.md)。

验证命令：`npm run typecheck`、`npm test`、`npm run test:playback`、`npm run verify:design-systems`、`npm run build`、`npm run test:ui`、`npm run test:native`。性能复测脚本为 `scripts/perf-smoke.cjs`，结果与限制见 [PERFORMANCE_TEST6.md](PERFORMANCE_TEST6.md)。
