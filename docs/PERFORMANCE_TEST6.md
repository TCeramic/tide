# test.6 前台性能复测

2026-10-16，同一 Windows 电脑；真实 Electron 窗口、默认 1100×720、balanced、motion=1。对比修复前本地 test.5 与 test.6。每个场景预热约 2.5 秒、采样约 7 秒，按透镜首页、点阵首页、透镜歌词、点阵歌词顺序运行。歌词场景使用本地 60 秒静音 WAV 和每行 5 秒的逐字时间 fixture，保留真实音频播放、歌词填色和滚动。

| 场景 | CPU 修改前 | CPU 修改后 | 工作集修改前 | 工作集修改后 |
| --- | ---: | ---: | ---: | ---: |
| 透镜首页 | 12.14% | 0.86% | 758 MB | 374 MB |
| 点阵首页 | 12.79% | 1.56% | 874 MB | 409 MB |
| 透镜歌词播放 | 14.44% | 3.27% | 1122 MB | 555 MB |
| 点阵歌词播放 | 14.33% | 3.69% | 1076 MB | 614 MB |

CPU 为 `app.getAppMetrics()` 所报告进程的 `percentCPUUsage` 求和；工作集为这些进程的 `workingSetSize` 求和，可能不包含独立 API 子进程，不能直接视为任务管理器应用分组的同口径总量。数据是单次短时测量，不是所有设备、窗口尺寸、背景和歌词数据的保证。测试没有改系统调度或用户正在运行的播放器。

另以每行约 0.33 秒、四秒循环音频进行快速换行压力测试：透镜歌词 CPU 约从 14.78% 降到 6.83%，点阵约从 15.58% 降到 6.56%。此场景会持续触发滚动、行缩放和字形更新，比普通歌曲密集。

主要改动：删除旧背景 CSS 时钟；限制玻璃合成像素与装饰背景更新；过滤歌词 DOM 对玻璃几何的无效通知；减少点阵粒子与控件空闲刷新；切回透镜销毁点阵资源；缓存歌词时间行及文字测量；仅更新变化的字，使用遮罩变换替代逐帧渐变和重滤镜；音频可视化使用独立更新预算。独立桌面歌词维持原逻辑。

复测命令：`npm run test:perf`。设置 `TIDE_PERF_EXE` 可测某个已打包 Tide.exe；省略则测当前生产构建。`TIDE_PERF_OUTPUT` 指定输出目录，`TIDE_PERF_LINE_MS` 指定逐字 fixture 的每行时长，默认 5000 毫秒。与 UI 测试相同，需要可用的 Playwright 或 `TIDE_PLAYWRIGHT_MODULE`。
