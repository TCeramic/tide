# Tide 0.9.2-test.8

## 本次变更

- 灵感模式仅在队列最后一首随机续接一首；中途切歌保留原歌单顺序，重新打开歌单重新抽样，整表风格和喜欢权重保留。
- 透镜/点阵分别保存明亮与深色模式；性能档位为低、中、高。
- 点阵鼠标环复用原版圆环、轮廓聚拢和弹簧物理，改为局部画布并限制绘制频率为60Hz；退出主题/窗口不可见时清理或暂停。颜色和轮廓缓存，不监听无关的逐帧根样式变化。
- 点阵背景不再因悬停普通按钮就提高模拟频率，鼠标事件合并到渲染帧处理；中档背景物理像素上限约110万，高档180万、低档70万，减少大窗口GPU与合成开销。按钮上的粒子环不再同时推动背景粒子。
- 歌曲进度条使用原仓库 mountProgress 的气体凝成晶格动画，已播放部分锁定成三行彩色点阵，未播放部分为散点；保留原生拖动、键盘跳转和时间预览。暂停后收敛并停止持续重绘，颜色和尺寸按需更新，关闭时清理观察器；不播放进度组件提示音。
- 桌面歌词参考 Mineradio 重新实现透明视窗、暖色高亮、边缘渐隐、长句滚动、逐行透视入场和悬停控制；新增独立的未唱/已唱颜色与字体预设及自定义字体名称。设置持久化并在窗口准备完成后重发初始样式。
- 保留今日潮汐20首刷新、系统托盘后台播放、音乐脉络四层独立页面及其他前序修复。

## 验证与限制

133项单元测试、类型检查、构建与70份上游原文件哈希通过。实际主进程+HTTP fixture验证分页、队尾随机续接、重开歌单重抽样和潮汐刷新；Edge验证四种主题、局部光环画布、物理像素预算、小窗口、逐字歌词和进度拖动时间。真实Electron验证颜色/字体控件持久化、桌面窗口初始颜色、长歌词、逐行入场、锁定关闭及托盘后台音频。

交互压力脚本 scripts/interaction-perf.cjs 在大窗口模拟鼠标移动与悬停，记录RAF间隔、Electron进程CPU和画布像素。短测未复现持续长帧；RAF间隔不等于点阵或光环的实际绘制频率，进程内存可能受Windows工作集回收影响，不能据此承诺用户机器已经完全消除卡顿。确定的优化为画布范围、像素预算、事件合并和无效重绘清理。
