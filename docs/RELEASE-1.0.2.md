# Tide 1.0.2 Windows

- 设置分为外观、播放、快捷键、桌面歌词和关于，移除指令总线、AI服务配置及调试提示的客户端入口。
- 设置分类按钮文字居中；桌面歌词按显示、文字、效果分组，统一开关、滑杆数值及颜色控件。
- 左上角小窗按钮支持再次点击关闭。
- 关于页显示版本、GitHub仓库、手动检查更新和最新发布日志。
- 每次启动自动检查稳定版；可选择更新、稍后、今天不再提示。手动检查不受今日免提示影响。
- 默认使用 GH-Proxy 第三方加速下载公开安装包，可改官方源或自定义HTTPS镜像；失败回退官方源，SHA-256校验通过才允许解压启动。镜像不接收账号凭据。网络速度取决于所在地与服务状态。
- 新版解压到独立目录，保留旧程序，沿用账号和设置。
- 保留换行歌词高亮修复及蓝色潮汐程序图标。

仓库源码公开。新增自有改动采用 GPL-3.0-only，第三方组件与历史MIT版本保留原许可。对应源码及构建说明见本次版本标签。

Windows ZIP仍为便携包，下载更新后会询问是否解压并启动新版。首次需要手动下载本版，旧版本没有更新功能。
