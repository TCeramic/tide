# Tide 0.9.2-test.5

## 功能

- 「音乐脉络」作为主界面的独立页面，替代原来的证明树容器。明确的返回主页、返回上一级和面包屑；只使用当前播放队列，按「当前播放列表 → 歌手 → 专辑 → 单曲」逐层浏览，单曲点击播放。
- 直接使用固定版本 MIT 上游 `design-systems/lattice/src/gl/prooftree.js`，不修改原文件。每次仅传入当前节点及最多 8 个直接子节点，超出分页；透明画布、节点文字和右侧目录随 Lens/Lattice 配色。
- 专辑编号和标题从云端歌曲数据保留到播放队列；没有专辑信息时明确显示「未标注专辑」。
- 灵感模式保留原始列表画像；每轮在整个已载入原始列表上分段取样最多 8 首，并额外加入最多 4 首喜欢歌曲。取样随轮次轮换，喜欢歌曲投票权重为普通歌曲的 3 倍；按多来源投票和相似结果排名合并，去重后追加最多 8 首。新推荐不会取代原始画像。
- 云歌单每页 100 首。播放到剩余 10 首时预读下一页；原歌单尚未读完时不插入推荐。页面提供加载更多，失败保留队列并在后续切歌时重试；重复页面停止续读，旧队列的异步结果不会写入新队列。
- 删除底栏音乐符号的歌词按钮；小封面和歌词页大封面切换歌词页/上一页，保留搜索、选中项及滚动位置。
- 曲目更多菜单脱离列表布局，支持右键、点外关闭、Escape 和键盘上下选择。歌单、音质的原生下拉选项使用明确的深底浅字。
- 原生窗口控制区透明并保留主题对应的图标颜色；关闭时选择最小化到任务栏、退出或取消。
- 主窗口最小化/隐藏时暂停场景时钟、原版点阵共享时钟、粒子、玻璃合成、Paper 背景、歌词绘制、歌名滚动与音频可视化，并推迟常规播放 UI 更新；保留音频和独立桌面歌词。恢复时同步最新播放状态。队列仅在内容或当前曲目变化时重建。

## 验证

- 类型检查、129 项单元测试、生产构建、70 项上游原文件哈希校验。
- `npm run test:playback`：真实主进程播放控制实现 + 本地 HTTP fixture，验证自动分页、原始列表取样、喜欢权重、旧请求隔离。
- `npm run test:ui`：Edge 渲染 + IPC fixture，验证独立页面、四层导航、8 节点分页、面包屑、返回、两种主题、封面切换与上一页状态、菜单不挤动列表、下拉可读性；保留设置滚动、歌词连续逐字填色及三种尺寸回归。
- `npm run test:native`：真实 Electron / preload / API，隔离 userData，验证本地 WAV 导入、实际播放、时长、跳转、关闭选择最小化后音频继续和桌面歌词继续收取逐字进度。文件选择和关闭选择使用固定响应。

## 限制

测试包未签名。真实云账号的登录、歌单权限与推荐质量仍需用户账号测试；专项分页和推荐测试使用确定性本地响应。未调用真实模型，AI 保持框架与本地取色；本地音乐内嵌封面尚未提取，序曲未加入。音乐脉络显示当前已经载入的播放队列，继续载入后重新打开可查看新歌曲。
