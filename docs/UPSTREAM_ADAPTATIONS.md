## 本次行为

- 透镜设置面板恢复纵向滚动。播放队列改为左侧边缘悬停/聚焦展开，离开自动收起。
- 底栏控制区固定尺寸；长歌名裁剪，并延迟循环滚动。进度条占底栏宽度 86%，保留两侧留白；拖动显示目标时间 / 总时长。本地音频加载元数据后补回真实时长。
- 今日潮汐保留听歌历史封面，并为缺失封面批量补查询。
- 歌词页支持逐字填色、当前行缩放/淡化、点击跳转；手动滚动暂停跟随六秒，可立即恢复。支持原文、翻译、罗马音及时间偏移。
- TTML 查询设置超时、体积限制、缓存与并发去重；失败回退现有云歌词。无实测逐字时间的 AI 分词明确标注为估算时间，模型不负责生成时间戳。

## 不配置 API 也能生成主题的原因

Folia 的 `useThemeController` 在缺少模型密钥时调用本地 `generateBuiltinDualTheme`。Tide 同样提供本地封面取色：在浏览器读取封面像素生成配色，图片不可读取时用曲目种子生成确定性配色。这些操作不调用模型、不收费；界面明确说明本地生成。

歌词页展开「主题与 AI 辅助」可生成本地配色、复制提示词或粘贴主题/分词 JSON。自动模型按钮在未配置时禁用。主题只接受安全十六进制颜色；分词必须逐字保留原文、空格和标点，禁止改变行数。

## 模型适配器（框架已完成）

主进程从启动环境读取 `.env.example` 列出的变量，支持 Gemini 和 OpenAI-compatible 接口。不会自动读取 `.env` 文件；可由启动器设置环境变量。凭据只存在主进程，不进入渲染器、日志或报错文本。HTTPS 为默认要求，HTTP 仅允许回环地址。请求有 45 秒超时和响应大小限制，一次只运行一个任务。

本次按用户要求只完成框架：没有创建密钥，没有请求真实模型。已用本地测试传输验证适配器与结构化响应校验；真实服务的模型名称、兼容性和计费行为需配置后验证。

## 验证与边界

125 项单元测试、类型检查、构建和 70 项原版源码哈希校验通过。Edge 渲染器 + IPC fixture 检查两套外壳、设置滚动、队列显隐、长歌名、进度预览、逐字歌词、手动跟随、本地配色及 JSON 导入，零 pageerror。真实 Electron 测试检查本地 WAV 导入、播放、真实时长和跳转；文件选择器使用固定返回值。

本次未覆盖真实账号登录、云端音频权限、硬件媒体键或真实模型调用。本地音乐尚未提取内嵌封面。歌词页是针对 Tide 的交互适配，未宣称与 Folia 整页像素一致。
