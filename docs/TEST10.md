# test10 界面重构与验证（2026-10-17）

## 实现

- 首页继续播放置于左侧，扩大封面，其他入口在右侧；每日推荐并入歌单网格。本地音乐、每日推荐、歌单详情分别显示各自内容。
- 云端与内置歌单封面保持正方形。详情只显示当前歌单歌曲；开始播放按顺序从第一首可播放曲目开始，随机模式随机选择。
- Tide 自带歌单支持创建、编辑名称/封面/描述、收藏/移除歌曲、删除及本机持久化。可主动创建网易云副本并同步；失败保留本机数据，远端编号先保存，重试避免重复创建。
- 修复真实搜索链路遗漏 offset 导致下一页重复第一页的问题。分类点击即时刷新当前关键词；加载更多追加新页并去重。
- 音乐脉络恢复原版三维位置与自动旋转，当前分支延伸、其他分支淡化、返回收起；搜索和各级页码保留。扩大树的视野比例，标签保留名称。
- 播放栏改为底边触发的玻璃 Dock，移开后下移隐藏；两个主界面主题均使用原版透镜光学渲染。队列、设置、头像保留圆形按钮，离开触发区后隐藏；队列触发区为左侧中部及上部。
- 歌词页歌手可跳转搜索；封面下方改为潮汐波动；选项收进右上方圆形渐隐按钮；隐藏搜索栏和两列竖向滚动条，保留滚轮滚动。歌曲进度条不因隐藏滚动条而改变。
- 删除五个旧预设及对应样式分支。页面、模块、控制和背景使用统一动效，低档关闭、中档适度、高档完整。
- 封面配色采用像素 RGB/HEX 均值及主要色簇，驱动丰富流动背景。每首歌缓存一次、后续复用；封面稍后补全时可替换本地回退色，手动生成覆盖缓存。AI工具移到设置页，未调用模型服务。
- 独立小窗播放器提供封面、歌名、歌词、悬停播放控制、顺序、喜欢和进度；小窗独立切换透镜/点阵/透明风格，支持置顶、穿透及呼出主界面。穿透时保留独立可点击解锁按钮。喜欢状态在窗口间同步。
- 桌面歌词锁定时保留独立解锁入口；横向仅横向居中、竖向仅竖向居中，另一坐标不变。原有逐字、双行/翻译、置顶、右键菜单、显隐热键继续保留。

## 占用优化与特效保留

保留音乐脉络的三维旋转和原版点阵、玻璃光学效果。优化隐藏页面排版、重复标签尺寸测量、设置高频磁盘读取、重复喜欢更新及歌词帧调度；移除没有可见使用者的旧频谱分析路径。

Dock 隐藏后停止晶格进度绘制，小窗透明模式停止主题画布并释放像素缓冲；主窗口和小窗隐藏/最小化时停绘，恢复后重新开始。音频和桌面歌词使用独立时钟。

240Hz 测试环境中，高档鼠标环、晶格进度和点阵背景均测得约120次/秒绘制，画布像素约180万；中档分别约59、30、25次/秒。绘制计数不等同于屏幕实际呈现FPS。

已采集前台进程占用与动画回调数据；不同页面、窗口尺寸和运行环境会改变结果。此次不宣称所有页面CPU已降低到固定百分比，也不以删除三维/光学效果实现低占用。

## 验证

- 142项单元测试；类型检查、构建；70份原版 MIT 文件哈希验证。
- 实际 Electron → preload → 主进程 → HTTP → 网易云搜索，第一页20条、第二页20条且有不同ID。
- Edge实际渲染：封面比例、首页布局、入口分离、独立详情、播放起点、分页及即时分类、Dock显隐、歌词菜单、歌手跳转、隐藏滚动条、音乐脉络旋转/分支/返回页码、创建/编辑内置歌单，无页面异常。
- Electron主进程专项：小窗独立风格/透明停绘/最小化恢复/穿透解锁；桌面歌词解锁/单轴居中；本机歌单持久化及同步失败保护。
- 真实WAV播放、桌面逐字/LRC估算/双行/翻译/前奏/纯音乐、字体颜色/置顶/方向/菜单/显隐热键，以及托盘后台播放。
- 点阵长按聚拢、升温、脉冲、松开/取消及主题清理；高档约120Hz绘制预算。

运行入口：`npm test`、`npm run typecheck`、`npm run verify:design-systems`、`npm run test:ui`、`npm run test:native`、`npm run test:mini`、`npm run test:playback`、`npm run test:cursor`、`npm run test:refresh`、`npm run test:search:live`。界面脚本需要设置 TIDE_PLAYWRIGHT_MODULE 到可用的 Playwright。

账号权限、云端创建/同步的真实写入尚未用登录账号验证；接口和错误保护有本地回归测试。安装包未签名。AI为本地取色与可接服务框架。
