# Tide 0.9.2-test.9

本版直接复用原版透镜、点阵主题，包含前序TEST8全部改动，并完成以下修复。

- 点阵鼠标圈支持长按：约700ms逐步聚拢、升温、脉冲，松开散开回落；取消、失焦、离开窗口和切换主题清理状态。保留按钮点击；低档关闭装饰动画。
- 歌单页改为封面网格，点击封面进入独立歌单内容页，页首显示封面；今日潮汐提供专属生成封面。
- 搜索独立页面，每次读取20条、加载更多追加与去重，保留已加载结果；请求失败可重试，重复页/末页停止，过期查询不会覆盖新结果。支持单曲、歌手、专辑和歌词搜索。完整可用范围取决于上游搜索接口。
- 修复队尾从灵感模式切回循环时，清理未来推荐曲目丢失封面和专辑元数据的问题；队列删除、移动均保留元数据。
- 今日潮汐保存完整当日快照，刷新成功原子替换；退出重进和同日重启保留刷新结果，跨日重新生成。失败/空刷新保护当前可用列表，并发旧请求不能覆盖新结果。
- 高档背景、鼠标环、晶格进度目标120FPS；局部画布、像素预算、事件合并、暂停/隐藏停绘仍保留。实际240Hz显示环境的三者绘制频率约120Hz；中档鼠标环60Hz、进度30Hz、背景约27Hz。绘制计数不是GPU呈现FPS，不承诺所有机器无卡顿。
- 透镜/点阵、明暗切换从左上角圆形扩散；模块进出加入移动、渐隐渐显，高档附加缩放/模糊与逐项进入，中档适度，低档关闭。无常驻模块动画时钟。
- 音乐脉络保留同一渲染器、根节点和分支位置，歌手→专辑→单曲在当前分支延伸，其余分支淡化，返回反向收起。每级搜索/页码独立保留，右侧快速搜索；限制可见节点数、清理旧几何和纹理，低档无持续树动画。按后续确认采用点击歌手展开，而非默认铺开全部专辑。
- 桌面歌词支持真实YRC逐字及无词级时间时的逐行估算扫过；估算不冒充真实逐字时间。原文单/双行独立于小字翻译；前奏、无歌词和纯音乐提示显示歌曲与歌手。默认置顶。
- 桌面歌词有主题对应的独立轻量右键菜单：穿透锁定、方向、行数、翻译、高亮、动效、波形、字号、透明度、光晕、字体及隐藏。歌词页移除入口，仅设置页保留完整配置。
- 桌面歌词横竖切换保留原视觉中心，靠边时整窗夹在屏幕可用区域；只提供显隐全局热键，默认Ctrl+Alt+D，可更改或关闭。托盘提示仅显示“潮汐 Tide”。

验证：139项单元测试、类型检查、构建和70份上游原文件哈希通过。主进程+真实HTTP测试覆盖队尾推荐、切循环保留封面、歌单续读、旧请求保护、潮汐刷新及再次读取。Edge测试覆盖分页20→40→43、独立搜索页、封面进入/返回、四种主题、小窗口、音乐脉络搜索/页码/分支、进度拖动与歌词。实际Electron覆盖桌面逐字、LRC扫过、双行/翻译、前奏/纯音乐、置顶、位置、快捷菜单、字体颜色与托盘后台音频。点阵长按与120Hz绘制另有专项脚本。

测试脚本：`npm test`、`npm run typecheck`、`npm run verify:design-systems`、`npm run test:playback`、`npm run test:ui`、`npm run test:native`、`npm run test:cursor`、`npm run test:refresh`。
