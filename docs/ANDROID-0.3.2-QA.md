# Android 0.3.2 测试版

- 歌词：单击返回封面，手动滑动显示虚线定位和确认跳转；语言与歌曲操作集中到右上角下拉菜单。
- 播放：队列采用可关闭、下滑收起的底部面板，不参与页面返回路径；播放模式使用独立图标，加入队列末尾相似歌曲续播的灵感模式。
- 歌单与账号：创建歌单入口、进入自动刷新、每日推荐歌单、今日潮汐刷新；登录头像及独立账号登录/切换/退出入口。
- 搜索：歌曲、歌手、专辑、歌单分类，分页追加且保持滚动位置。
- 按压：视觉反馈和尊重系统设置的轻触觉反馈；确认拖动进度时反馈一次。
- 横屏：独立播放与歌词网格布局，TIDE 位置固定于内容槽位；旋转保留 WebView 和当前页面，移动端点阵数量及粒径降低。

## 验证

- 163 项现有单元测试、TypeScript 和 70 个上游文件完整性校验通过。
- APK Web 资源的浏览器桥接测试覆盖四类搜索、分页位置、歌词滑动确认与单击返回、队列关闭、四种模式、登录表单与 320/600/740/926 宽度布局。
- 一加 Ace 3 / ColorOS 16 / Android 16 实机：读取头像、我的歌单与每日推荐歌单，搜索返回 20 首歌曲及 16 位歌手；75 行歌词、794×361 横屏保留歌词页、队列返回、透镜显示和分页滚动位置保持均验证通过。
- 创建歌单、退出账号及真实账号的喜欢操作未在测试中提交，避免更改用户账号数据；其控件与请求路径经过构建和桥接验证。
- 触觉反馈已接入系统 View.performHapticFeedback，实际手感需用户确认。
- 通知栏喜欢按钮已由用户确认显示；ColorOS 流体云独立喜欢按钮仍未显示，本轮未宣称解决。
