# Tide 1.1.3

## 本次修复

- **推荐歌单详情不再显示今日潮汐封面**：歌单详情原来在缺少封面时统一回退到 `assets/today-tide.png`，
  推荐歌单（`/personalized`）不在本地歌单列表里，拿不到封面就显示成今日潮汐。
  现在只有本地占位图（今日潮汐 / 每日推荐）走本地资源，网络封面一律交给封面渲染器，
  加载失败时退回潮汐波纹标记；打开详情的三处入口都会把歌单封面传进去。
- **歌单详情可刷新**：详情页标题旁新增「刷新歌单」，重新拉取当前歌单的歌曲与封面。
- **推荐歌单可换一批**：歌单列表「更多推荐」分隔线上新增「换一批」，重新请求 `/personalized`。
- **打开歌单详情时回到顶部**：原来会保留列表页的滚动位置，导致详情头图与标题被顶出可视区。

## 发布要求（云更新）

- Release tag 必须是 `v1.1.3`。
- 资产名必须逐字为 `Tide-Setup-1.1.3-x64.exe`（优先）或 `Tide-1.1.3-win.zip`（回退）。
- 建议同传 `SHA256SUMS.txt`，每行格式 `<64 位小写 sha256>  <资产名>`。
- 资产链接必须位于 `https://github.com/TCeramic/tide/releases/download/` 之下。
- 本次构建产物见下方「本次构建产物」。
