# 舞台效果路线图

2026-10-17。本轮先交付布局、连续渲染切换、点集轮换、像素封面和小窗修复。

1. Liquid Metal：本轮应用到 Lens 主页 TIDE 标识。可见才渲染，低性能档静态，限制在小画布中；后续可做播放器播放键的可选材质。
2. 商籁：下一阶段独立歌词舞台，先做逐行排版、镜头推进和逐字节奏，再加音符/图形缓存。保留常规歌词页作为默认。
3. 绘光：随后增加体积光束、轻雾与描边舞台；用平滑低频驱动空间变形，不用全屏明灭。
4. 音符轨道/空间光谱：最后扩展可选主题与多档性能预算。高档保留高帧率，隐藏/后台停绘。

每个舞台需要独立入口、强度控制、减少动态效果设置、窗口缩放测试、长时间播放/切歌及 GPU 资源回归。上述 2—4 项属于待实现项，不计为本版已完成功能。
