# Tide 1.0.0 Windows

- 新增莫比乌斯带、水母、旋涡星系、蝠鲼、宇宙花与蝴蝶六种立体点集，共 16 组，继续每 22 秒自动切换，也可手动切换。
- 将弹簧点集重绘为 DNA 双螺旋，增加两条骨架之间的碱基横档。
- 删除设置页“透镜 · 完整组件”和“点阵 · 完整组件”两个展示入口。
- 扩散过程中只同步发生变化的歌词样式和滚动状态，避免重复 DOM 写入触发透镜几何重算；保留完整帧率、原画面继续渲染和遮罩扩散。

验证：158 项测试、类型检查、构建、16 点集/自动轮换 UI、DNA 连接横档、扩散像素与姿态连续性回归。增加扩散帧耗时记录工具；首次初始化仍可能存在短暂长帧，不能把平均帧率等同于完全无卡顿。

这是桌面端正式版；Android 仍独立测试，不随此版本变更 APK。
