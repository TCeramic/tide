# test12：窗口自适应与扩散回归修复

2026-10-17。test11 的发布在用户反馈后停止；本版保留其已实现功能并修复实际画面缺陷。

## 窗口及布局

- Lens 宿主由 #app 迁到 body 后，依赖 #app.lg-stage 的定位规则失效，使搜索栏、歌单、音乐脉络等变成相对定位，超出窗口。改为与宿主无关的 #app 定位规则，原版设计系统文件不变。
- 缩小窗口后收窄队列、头像、设置的透明悬停区域，避免挡住主页和搜索按钮；短窗口为点集切换按钮保留独立高度，避免遮住本地音乐操作。
- 搜索栏、歌单总览/详情、本地音乐、搜索结果、音乐脉络使用当前视口重新计算边距与可用高度；低高度窗口减小封面和间距，操作行换行，树及列表共同缩放。
- 歌词封面随窗口高度缩小，歌名、歌手保留可用空间；长内容可在隐藏滚动条的区域继续滚动。TIDE 横向跟随封面中心，短窗口调整高度和纵向安全边界。
- 树标签先隐藏，等首帧投影后再显示，禁用随帧更新坐标的 CSS 位移动画，避免初始化堆叠或标签追赶树体。
- 关闭菜单位置独立于 Lens 通用相对定位样式，固定在窗口右上角，且限制高度、保留内部滚动。
- 小窗歌词缩小并紧贴歌名/歌手下方，保留右侧空白；封面和上次位置/设置保留。

## 扩散、背景及导航

- 用当前主窗口合成画面的临时内存快照覆盖旧外观，径向透明遮罩从左上角揭示实时新外观；按整个视口对角线计算终点，温和减速，真正到达右下角才清理遮罩。无 ViewTransition 提前结束行为。
- 流动背景、像素封面和前景同时参与明暗扩散；Lens 恢复时立即准备有效 GPU 首帧，避免黑屏。后台隐藏、低性能档或减少动态效果时不创建动画。
- 一次切换仅保留一张临时快照和一个有限时长回调；完成后释放。音频时钟保持独立，不暂停播放。
- 音频只推动流动坐标的局部变形，低频、鼓点使用平滑包络；移除鼓点驱动的整体亮度及网点尺寸脉冲。
- 半色调像素根据流动的局部纹理与条带分布，保留平滑区域；移除满屏均匀像素覆盖。
- 页面跳转不再创建丢失 #app 样式作用域的旧页面克隆；已在主页时再次点击主页不做可见状态切换。
- 桌面歌词和小窗锁定按钮点击后清除按钮焦点，离开鼠标热点后继续自动隐藏。

## 验证

- npm test：144 项；typecheck、build、70 个原版文件哈希验证。
- Browser plugin not available；使用项目 Playwright 测试真实渲染页面与确定性 IPC fixture。两套外观各测试 800×560、1100×720、1700×1050、再次缩小 900×600；验证搜索栏、歌单总览/详情、本地音乐、搜索、三维音乐脉络、歌词、设置、登录、调色、关闭及歌单编辑菜单边界，检查主页重复点击不改 hidden。
- 原生 Electron：150% DPI 下切换 Lens/Lattice、流动背景和像素封面明暗，比较扩散后段右下角实际合成像素与旧画面，要求角落到达前保留旧像素；Lens GPU 画面无全黑。结果保存 artifacts/theme-native/result.json。
- 原生小窗位置持久化、全屏、独立风格、透明停止绘制、桌面歌词轴向居中、锁定按钮离开后隐藏。
- ZIP/ASAR 与源码构建一致性、打包程序播放及后台资源回归在交付前执行。

Folia 商籁/绘光的源码评估见 FOLIA_EFFECTS.md，本版未实现两套完整演出系统。云端写入与真实跨应用鼠标穿透的物理命中仍需实际体验验证；没有固定 CPU/GPU 占比承诺。
