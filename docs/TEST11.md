## 调色菜单

设置中的「主题配色」打开独立小菜单，包含背景四色、强调色、主/次文字、点阵、模块底色和不透明度。示例搜索框、封面、歌词、点阵与 Dock 实时预览草稿，应用才写入设置；关闭放弃草稿，恢复自动配色保留可再次编辑的自定义值。全局自定义覆盖不会覆写每首歌曲的自动配色缓存。

## 小窗与桌面歌词

- 小窗封面扩大至 112px；歌名/歌手缩小，歌词放在歌名下方，右侧留白。悬停渐变显示播放控件、进度和窗口按钮。
- 小窗不占任务栏及 Alt-Tab。关闭立即保存当前位置及样式、置顶、穿透设置；呼出恢复，并将离屏位置限制在显示器可见区域。
- 小窗/桌面歌词都移除额外的外置解锁窗口，同一个锁定按钮循环切换。锁定后仅锁按钮附近可以恢复鼠标交互，其他部分仍穿透。
- Windows 非激活小窗若被系统最小化，再次呼出时使用保存状态重建窗口，避免 restore 失效。

## 流动/像素背景与优化

参考 [Paper Shaders](https://github.com/paper-design/shaders) 固定依赖 0.0.81，在原 Mesh Gradient 上增加 Tide 自有像素网点及封面着色扩展。新增「像素封面」背景：当前歌曲封面铺满、按主题着色、叠加像素纹理；换封面交叉渐变，读取失败沿用上一张有效封面或内置图。

音频来自实际播放元素的共享 Web Audio Analyser（FFT 512），低频能量与起音包络推动流动速度、扭曲和亮度。无可见背景时不采样，不新增常驻 RAF；低档或关闭动效时静态。远端播放使用仅接受音乐接口解析地址的本机限量中继，保留 Range 拖动并解决音频分析跨域问题，Cookie 不传给音频源；账户 API 不开放跨域读取。

透镜背景复用单个场景画布，尺寸不变时更新已有纹理，不再逐帧创建全屏 Canvas。Paper 帧内统一提交颜色、节拍、时间，避免同帧多次绘制。Dock 使用所在屏幕区域的背景裁切及动态更新，并提高亮度、降低高度、加强圆角裁切。隐藏 Dock、最小化主窗口和透明小窗停用对应渲染，恢复后重新更新。
